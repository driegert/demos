What’s going on?

We sample points (X, Y) uniformly from the unit square [0,1] × [0,1]. Every location in the square is equally likely.

The quarter disc x² + y² ≤ 1 has area π/4, while the square has area 1. Therefore the chance that a point lands inside is P(inside) = π/4.

Estimate: π̂ = 4 × (# inside) / n

Each point is a Bernoulli trial with p = π/4: it is either inside or outside. That gives

Standard error: SE(π̂) = 4√[p(1−p)/n] ≈ 1.642/√n

The typical size of the error (the SE) shrinks like 1/√n; the actual error on any one run keeps wobbling up and down as points are added. To gain roughly one more decimal place—10 times less typical error—we need about 100 times more points.

Approximate 95% interval: π̂ ± 1.96 × 4√[p̂(1−p̂)/n], using p̂ = (# inside)/n.

This interval relies on the normal approximation to the binomial, so the page only reports the SE and interval once there are at least 10 points inside and 10 outside. Before that, the plug-in SE can be exactly 0 (say, one point, outside), and the interval would collapse to a single value—clearly wrong.

This slow 1/√n convergence makes Monte Carlo a poor practical way to compute π, but it is a great way to see how random sampling estimates probabilities and areas.
