# Statistics demos

Small, self-contained interactive demos for statistics teaching. Hosted with GitHub Pages; one folder per demo, each with its own `index.html` and no build step.

| Demo | Folder | What it shows |
|---|---|---|
| Estimating π by Monte Carlo | [`estimate-pi/`](estimate-pi/) | Sample uniform points in the unit square; the fraction inside the quarter circle estimates π/4. |

## Adding a demo

1. Create a folder with a single `index.html` (inline CSS/JS, no external dependencies).
2. Add a row to the table above and a card in `index.html` at the repo root.
